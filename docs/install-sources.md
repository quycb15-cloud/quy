# Nguồn hướng dẫn cài đặt web app

Google Chrome Help, “Use web apps”: https://support.google.com/chrome/answer/9658361?hl=en&co=GENIE.Platform%3DDesktop. Trên máy tính: mở Chrome, vào website, chọn menu More → Cast, save, and share → Install page as app, hoặc chọn biểu tượng Install trên thanh địa chỉ.

Microsoft Support, “Install, manage, or uninstall apps in Microsoft Edge”: https://support.microsoft.com/en-us/edge/install-manage-or-uninstall-apps-in-microsoft-edge. Trên Edge: Settings and more → More tools → Apps → Install this site as an app; quản lý tại edge://apps.

Apple iPhone User Guide, “Turn a website into an app in Safari on iPhone”: https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios. Trên iPhone: Safari → website → Page Menu/Share → Add to Home Screen → bật Open as Web App → Add.
